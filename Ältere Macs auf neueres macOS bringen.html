Warum ein Upgrade?

Ältere Macs laufen oft noch zuverlässig, bekommen vom Hersteller aber irgendwann keine neuen macOS-Versionen mehr angeboten. Das hat Folgen im Alltag.

Fehlende Updates

Neuere macOS-Versionen erscheinen im Software-Update nicht mehr, obwohl die Hardware weiter funktioniert.

App-Kompatibilität

Viele Apps verlangen eine Mindestversion von macOS. Auf einem alten System bleiben aktuelle Versionen außen vor.

Träges Gefühl

Ein aktuelleres System bringt oft ein flüssigeres, moderneres Arbeiten: bessere Funktionen, neuere Oberfläche, mehr Auswahl an Software.

Unterstützte Geräte

Tippe auf eine Karte für mehr Details. Welche macOS-Version konkret möglich ist, hängt vom jeweiligen Modell und Baujahr ab.

Keine iMacs

iMacs sind ausdrücklich nicht Teil dieses Angebots.

Ablauf & Voraussetzungen

Drei Schritte, in dieser Reihenfolge.

Vorbereitung

  • Datensicherung (Backup) anlegen
  • Vom Apple-Account abmelden

Upgrade-Prozess

  • Das System wird vorbereitet
  • Die neuere macOS-Version wird installiert
  • Danach folgt ein Funktionscheck

Sicherheit & Rückkehr

Probleme können auftreten. Dein Mac lässt sich aber jederzeit auf die vorherige Version zurücksetzen.

Sicherheit & weitere Infos

Mit einem Backup und der Möglichkeit zur Rückkehr auf die vorherige Version bleibt dein Mac abgesichert.
